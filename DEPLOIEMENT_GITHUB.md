# Déploiement GitHub Pages en 5 minutes

1. Sur GitHub, créer un dépôt PUBLIC, par exemple `presence-charisme`.
2. Uploader tous les fichiers de ce dossier à la racine.
3. Ouvrir `Settings` → `Pages`.
4. Dans la source de publication, choisir la branche principale et le dossier `/ (root)`.
5. Enregistrer.
6. Attendre la publication puis ouvrir l'URL `https://<votre-compte>.github.io/presence-charisme/`.
7. Depuis le téléphone, utiliser le menu du navigateur pour installer l'application.

Ne mettez pas de données sensibles dans un dépôt public. La photo incluse dans ce paquet est destinée à un usage privé/pour le profil de l'utilisateur ; supprimez `avatar.png` avant publication publique si nécessaire.
